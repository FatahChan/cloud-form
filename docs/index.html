Cloud Form
Features Get started GitHub View repository

Open source · Cloudflare Workers

Forms that feel like Typeform, deploy like a single Worker.

Build welcome screens, question flows, and endings in a drag-and-drop admin. Publish to a public URL, collect submissions in D1, and store uploads in R2 — no separate backend to wire up.

Quick start Source on GitHub 
git clone https://github.com/FatahChan/cloud-form.git
cd cloud-form
npm install
npx wrangler login
npm run deploy

What you get

One repo, one Worker, SQLite via D1, files on R2, and a React admin built with TanStack Start.

Visual builder

Reorder questions, edit welcome and thank-you screens, and publish when the schema is valid.

Public player

Share /f/<slug> links. Respondents get a focused step-by-step experience.

Inbox & files

Review submissions per form, filter answers, and download attachments from R2.

Team & audit

Invite admins with expiring links. Owner setup once; audit log for form and user actions.

Schema migrations

Publishing creates or alters per-form tables so new fields land without manual SQL.

Edge-native stack

D1 and R2 bindings are provisioned on deploy. Session cookies and API routes run on the Worker.

Get started in minutes

After deploy, open your Worker URL, complete owner setup, then create your first form.

  1. Deploy to Cloudflare npm run deploy builds the app, pushes the Worker, and applies D1 migrations remotely.
  2. Create the owner Visit /admin/setup on your deployment to register the first account.
  3. Build & publish Use the admin builder, publish when ready, and share the public slug at /f/<slug>.

Built with

Modern React on the edge, with typed APIs and Worker-native storage.
