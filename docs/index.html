Open source · Cloudflare Workers

Forms that feel like Typeform, deploy like a single Worker.

A full Typeform-style builder and respondent experience on Cloudflare: multi-page flows, templates, searchable inbox, and file uploads — one Worker, D1, and R2. No separate API server.

Manual install Source on GitHub

One click forks the repo, provisions D1 and R2, and deploys via Workers Builds. Learn more 

git clone https://github.com/FatahChan/cloud-form.git
cd cloud-form
npm install
npx wrangler login
npm run deploy

Key features

Everything you need to design, publish, and operate forms — from first template to growing submission volume.

Typeform-style flows

Centered welcome and thank-you screens, progress bar, and multiple questions per step — respondents stay focused.

Starter templates

Contact, job application, NPS, events, and more. Preview the full flow, then create a draft in one click.

Visual builder

Drag-and-drop questions, organize pages in the sidebar, and publish when the schema is valid — with live preview.

Inbox & attachments

Searchable submission tables with cursor pagination. File uploads land in R2 and download from the admin inbox.

Public player

Share /f/<slug> links. Keyboard-friendly steps, phone fields, selects, and file questions.

Forms dashboard

Search and sort your forms. See who created and last updated each form before opening the builder.

Publish & schema DDL

Publishing creates or migrates per-form D1 tables so new fields work without hand-written SQL.

Team invites

Owner setup once at /admin/setup. Invite teammates with expiring join links from Team.

Audit log

Track form publishes, team changes, and other admin actions in one place for accountability.

Edge-native & themed admin

Single Cloudflare Worker with D1 and R2 on deploy. Light and dark mode across the admin experience.

Field types & responses

Build the questions you actually need; answers map cleanly into structured storage.

Question types

  • Short and long text, email, phone (validated)
  • Single and multi select, numbers, and dates
  • File upload with size and type limits (R2)
  • Statement blocks for instructions between steps

How responses are stored

  • Metadata and auth in shared D1 tables
  • Per-form answer columns after publish
  • Attachments keyed to submissions in R2
  • API routes and sessions on the same Worker

Get started in minutes

After deploy, open your Worker URL, complete owner setup, then create your first form.

  1. Deploy to Cloudflare Use the Deploy to Cloudflare button, or run npm run deploy locally after wrangler login.
  2. Create the owner Visit /admin/setup on your deployment to register the first account.
  3. Pick a template or start blank Open /admin/templates to preview a layout, or create a form from the Forms list.
  4. Build & publish Customize in the builder, publish when ready, and share the public slug at /f/<slug>.
